# El viaje oculto del agua

Proyecto del segundo parcial sobre el recorrido del agua: desde que llega a casa hasta que se va por el drenaje y recibe tratamiento. El sitio continúa el proyecto del primer parcial.

## Estructura del proyecto

```text
.
├── css/
│   ├── estilos.css
│   └── normalize.css
├── images/
│   ├── casa.jpg
│   ├── contacto.jpg
│   ├── cuidado.jpg
│   ├── drenaje.jpg
│   ├── portada.jpg
│   └── tratamiento.jpg
├── pages/
│   ├── casa.html
│   ├── contacto.html
│   ├── cuidado.html
│   ├── drenaje.html
│   └── tratamiento.html
├── index.html
└── README.md
```

## Páginas

- **Inicio:** presenta el recorrido del agua.
- **El agua en casa:** explica de dónde viene y cómo llega a la llave.
- **El drenaje:** describe el camino del agua después de usarla.
- **Tratamiento:** muestra algunos pasos para limpiar el agua residual.
- **Cuidar el agua:** reúne acciones para usarla con responsabilidad.
- **Contacto:** explica el propósito del proyecto y presenta a su autor.

## Tecnologías utilizadas

- HTML5 y etiquetas semánticas.
- CSS externo en `css/estilos.css`.
- Normalize.css en `css/normalize.css`.
- Flexbox para acomodar los elementos.
- Metodología BEM para nombrar las clases de CSS.

## Abrir el sitio

Abre `index.html` en un navegador. También puedes abrir la carpeta del proyecto en Visual Studio Code y ejecutar `index.html` con Live Server.
